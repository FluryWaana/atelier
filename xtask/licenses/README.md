# Offline third-party license supplements

The notice generator inventories Cargo.lock registry packages, including tools and all target platforms. Some published crate archives declare a license but omit its text. The JSON files here supply explicit, version-specific upstream evidence for those archives and explicitly identified embedded components. This is an inventory of upstream declarations, not a legal certification.

Each entry binds the package name, version, declared license, repository metadata, registry checksum and `.cargo_vcs_info.json` revision. Each text records an official source URL and its SHA-256. Generation is offline and refuses unknown missing texts, changed identities, revisions or text bytes. Existing license texts bundled in crate archives remain collected, including when an embedded component has an additional explicit supplement. Every component also links its exact source archive in the generated notices.

The objc2 family supplements preserve the complete upstream LICENSE.md at each crate revision, including its explanation of the Apple SDK-derived bindings. That file expressly links the MIT license. The separate SPDX-MIT.txt is the exact SPDX standard text at commit 31ba1a50e5397e00a304dbadc76531740e89ee48; its upstream placeholders are retained verbatim. No author, copyright holder or year has been invented. Selecting MIT from an upstream alternative does not alter the upstream declaration.

See connector-supplements-provenance.md for Mozilla's exact MPL text and its separate source revision, leptos-supplements-provenance.md for the explicitly documented replacement source revisions where a recorded Cargo revision is unavailable, and other-supplements-provenance.md for declarations in manifest files, r-efi's AUTHORS and the Apache-2.0 selection for wasm-split. Collection and generator regression scenarios are implementation candidates until the final campaign executes them; storing a text is not a passed package qualification.

Native-source review: libsqlite3-sys 0.38.2 embeds SQLite 3.53.2, Fossil check-in d6e03d8c777cfa2d35e3b60d8ec3e0187f3e. Its wrapper LICENSE is MIT, but sqlite3/sqlite3.c separately disclaims copyright and gives a blessing. The complete dated comment is preserved byte-for-byte as a supplemental notice, linked to the exact rusqlite source revision and pinned registry checksum; it supplements the wrapper license rather than replacing it. The generator therefore processes explicit supplements even when a wrapper already ships a LICENSE. A source review also found aws-lc-sys's aws-lc/LICENSE and third_party/fiat/LICENSE, and ring's LICENSE-* files covered by the existing recursive collection. These are source observations, not an executed package qualification.
