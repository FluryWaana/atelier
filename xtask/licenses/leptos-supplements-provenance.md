# Leptos MIT license provenance

The 21 records in `leptos-supplements.json` retain each locked crate version,
its MIT declaration, original repository and `.cargo_vcs_info.json` commit,
and its registry checksum from `Cargo.lock`. Text files were copied as exact
bytes from the official `leptos-rs/leptos` repository and carry SHA-256 hashes.
All 21 license texts have the same bytes, including the upstream copyright
notice `Copyright (c) 2022 Greg Johnston`; no attribution was reconstructed.

Fifteen records resolve `LICENSE` at the original crate source commit. For the
six records listed below, the official GitHub contents API could not resolve
that commit. Their license-text URL instead pins the official project's
`LICENSE` at `8d69739866fcd56e5483bb4a9c09350b8773089a`; their manifest `commit`
continues to identify the original crate metadata. We do not claim that the
fallback URL is a file recovered from the unavailable crate source revision.
This fallback text is byte-identical to the texts retrieved at the fifteen
available original revisions. No SPDX template substitution is used here.
