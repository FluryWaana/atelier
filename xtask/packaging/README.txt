Atelier Kanban

A local workspace for tasks, coding agents, Git reviews and time tracking.
The interface is available in English and French.
Atelier Kanban is in preproduction.

Installation

Use the platform installer or follow the portable installation instructions.
An update archive is a payload, not an initialized portable installation.
After installation, open the application shortcut or run the installed launcher.
The launcher opens an authenticated browser session on your computer.
Use the launcher's --help option for commands and --version for its version.
