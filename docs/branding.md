# Brand assets

The Atelier Kanban logo represents three Kanban columns with lavender and mint cards on a charcoal tile. Its symbol has no text so it remains recognizable at small sizes.

| Asset | Use |
| --- | --- |
| [Master PNG](branding/atelier-kanban-master.png) | Source artwork |
| [Application PNG](branding/atelier-kanban.png) | 512 by 512 pixel icon and README logo |
| [Windows ICO](branding/atelier-kanban.ico) | Windows icon at 16, 32, 48, 64 and 256 pixels |
| [UI PNG](../crates/atelier-ui/atelier-kanban.png) | Application interface asset |

Use the supplied files and preserve their proportions and transparency. Keep enough surrounding space for the rounded tile to remain distinct. Use the public name Atelier Kanban in documentation, launchers and package metadata.

## Colors

| Color | Value |
| --- | --- |
| Lavender | `#bfa5ed` |
| Mint | `#9bcbb5` |
| Charcoal | `#191b24` |

Keep exports consistent across the UI and native packages when updating the master artwork.
