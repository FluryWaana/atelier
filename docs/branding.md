# Identité visuelle

Le logo représente des cartes Kanban en trois colonnes, en lavande et menthe sur une tuile anthracite. Il reste sans texte pour servir d’icône à petite taille.

- Source : `docs/branding/atelier-kanban-master.png` (image générée avec l’outil intégré imagegen).
- Export PNG produit conservé : [atelier-kanban.png](branding/atelier-kanban.png), 512 × 512 pixels.
- Export Windows conservé : [atelier-kanban.ico](branding/atelier-kanban.ico), tailles 16, 32, 48, 64 et 256 pixels.

Les exports sont des réductions de la source avec transparence conservée. Ils sont préservés sans modification lors du retrait de l’ancienne arborescence Node ; leur présence ne prouve pas qu’un paquet Rust les utilise déjà. Pour renouveler le logo, régénérer ces exports avant de les intégrer aux paquets. L’icône ICO contient une image PNG par taille.

A single bold, minimalist flat geometric symbol: three vertical Kanban columns made of a few rounded rectangular cards, arranged to subtly suggest the letter A and forward progress. Strong recognizable silhouette, generous spacing, very few shapes, readable at 24px. Palette: warm lavender #bfa5ed as the dominant color with a small mint #9bcbb5 accent, on a deep charcoal #191b24 rounded-square tile. Polished independent developer productivity app, friendly and precise, restrained rather than corporate. Front-on orthographic vector-like flat fills, crisp edges, centered composition, square image. Tile occupies about 90 percent of the canvas, transparent outside its rounded corners. No text, no letters drawn as typography, no words, no mockup, no perspective, no decorative objects, no shadows, no gradients. One icon only. Save the generated image as a project asset if supported.
