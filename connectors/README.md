# Connecteurs locaux

Placez chaque module dans son propre dossier : `connectors/mon-module/index.mjs`,
puis redémarrez Atelier. Les fichiers du module restent séparés des fichiers
gérés par les mises à jour de l’application.

Pour démarrer, copiez `examples/connectors/demo` ici et suivez
[le guide des connecteurs](../docs/connectors.md).

Un connecteur est du code Node.js exécuté localement avec les droits de
l’application. Installez uniquement des modules dont vous acceptez le code.
